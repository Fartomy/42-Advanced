# Ecole 42 Advanced Projects

| Project Name    | Description  |
| :-------------: | :-----: |
| **libasm**       |  The aim of this project is to become familiar with assembly language.  |
| **cloud-1**      |   This project is an introduction to cloud servers.   |
| **ft_linux**     |    The first project of the Kernel branch! This is a simple LFS (Linux From Scratch) so that you can build your own distribution.  |
| **badass**       | The purpose of this project is to deepen your knowledge of NetPractice. You will have to simulate several networks (VXLAN+BGP-EVPN) in GNS3.  |
| **Unity Piscine 0**   |    Learn Unity basics by building a 3D game with movement, jumping, level design, and simple game-over logic.  |
| **Unity Piscine 1**   |    3D physics, Tags, Layers and Scene  |
| **Unity Piscine 2**   |    2D environment, tiles and sprites  |
| **Unity Piscine 3**   |    Advanced inputs and 2D GUI  |
| **Unity Piscine 4**   |    Animations and Sound  |
| **Unity Piscine 5**   |    Singleton, PlayerPrefs and Coroutines  |
| **Unity Piscine 6**   |    Navmesh, Light, Sound and Camera  |
